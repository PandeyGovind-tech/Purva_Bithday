# Purva's Birthday Website ❤️
Open `index.html` in any browser. No install needed.

**Photos** – put JPGs in `images/` with these exact names: hero.jpg and gallery1-6.jpg. Missing photos show a placeholder.
**Music** – put your song at `music/birthday-song.mp3`. It starts after the first click/tap (browsers block autoplay); the ♪ button toggles it.
**Love letter** – edit the `<p>` lines inside `<section id="letter">` in `index.html`.
**Funny cards** – edit the `<div class="card">` blocks in `<section id="funny">` in `index.html` (emoji, title, text).
**Gallery captions** – edit `data-cap="..."` on each gallery `<figure>`.
**Colours/fonts** – tokens at the top of `css/style.css`.
**Publish** – drag the whole `purva-birthday` folder onto Netlify Drop (app.netlify.com/drop), or push to GitHub and enable GitHub Pages. Share the link.
